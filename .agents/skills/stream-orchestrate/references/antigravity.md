# Antigravity

Use the common workflow in the environment-assigned checkout. Automatic orchestration is
unverified: inspect loaded conversation creation, isolation, messaging and completion tools.
Require a separately steerable task and its actual isolated checkout. Do not hardcode
`Workspace: inherit`, `Workspace: branch`, or old sibling paths; use only the current schema
and verify the resulting directory/base before implementation.

If the host cannot create that kind of task, provide launch briefs for manually created
conversations. Ordinary same-task subagents do not need this orchestrator. Follow reactive
completion notifications when available; avoid polling unchanged state. Preserve adopted
tasks and run `stream-start` in new tasks to prepare branches and references.

Finish sequentially from an accessible integration checkout. No sibling-write probe,
blanket permission widening, permanent stream directory, or custom lease exchange is needed.
