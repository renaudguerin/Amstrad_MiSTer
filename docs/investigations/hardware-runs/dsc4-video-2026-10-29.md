## AmSpirit discriminator and limits

The local SDL installation is Lite 1.15.1 and failed startup. The existing shared
Mac-mini instance was reachable at Lite 1.16.0/core 2491682 and used serially by A.
`amspirit-v2-dsc4/` records an uninterrupted disk boot, effective classic 6128,
CRTC1, 128K, French ROM, colour, monitor shader Off. Input is the same command;
near 52 seconds after typing completes, the image is a coherent otter. A further
1500-frame continuation (`dsc4-ams-t82.png`) shows movement/effects without the
FPGA's dense fragmentation. Elapsed time alone is not scene or hidden-state
identity; this is diagnostic disagreement, not a CPC correctness verdict.

The paused checkpoint has RAM mode 2: CPU 0000/4000/8000/C000 map to extension
banks 4/5/6/7. A replay using the base 64K would execute unrelated bytes.
The SNA has version 2,128K RAM and an `SPRT` chunk, SHA-256
`802842cac2c2cfaa9984300f5221d7e96bb35f4e543bbe88e530142668f275bb`.
Its byte A4 is not a version 2 CRTC-type declaration; live config/state identify
CRTC1. Record explicit CRTC1/keep when loading it. Neither classic hidden CRTC
state nor AmSpirit's `SPRT` state is completely restored by our loader.

The retained 60000-instruction history contains six repetitions of this actual
executed code, decoded using the active extension-bank mapping:

| PC | Operation |
| --- | --- |
| C04F/C052 | BC=BC08, DE=0305 |
| C055/C057 | select R8, change port toBD08 |
| C058/C05A | write R8=3, then0 |
| C05D/C05F | select R5, change port toBD08 |
| C060/C062 | write R5=5, then0 |

This establishes that the supplied title exercises the R8-toggle/R5-transition
combination in continuous execution. It makes the existing RFD/interlace
interaction a concrete next discriminator, **not an established cause**.
History is not a timestamped FPGA bus trace; no CRTC counter/parity/address
expectation has been read back from this emulator and called a hardware rule.

Next bounded unit: reproduce the authentic caller and preceding state through
production T80; correlate C058/C05A/C060/C062 acceptance with C0/C4/C9, effective
IVM, ParityFrame/ParityC9, RFD and VMA, then video-fetch address/byte and pre-filter
pixel. Read the relevant French ACCC rule directly before deriving a failing
expectation. A snapshot-only cold entry cannot settle a history-dependent
mismatch. Retain continuous reproduction and identify the **first** disagreement
before changing a shared counter or GA rule. No raw FPGA trace exists in this
bundle, so CRTC addressing, CPU timing, memory/GA consumption and acquisition
are not yet separated.
