# Type 0 R0 widening at the terminal character

At `1e95fa0a802ea0cf04bb7e06d50dff9370e204b8`, two private bits remember a pending vertical step. The row writer sees their OR. One bit can carry that obligation across both early and direct writes, including a simultaneous consumption and new admission. The already distinct horizontal decision still needs its own comparison history. For a late write with old R0=1, two horizontal models fit the original-CPC evidence and put the next raw HSYNC pulse **two character clocks apart**. The paired test below reaches that case with production CPU/GA timing.

## State that can be removed

At the frozen SHA, `rtl/crtc_type0_engine.v:318–347,618–639` has an early-write bit W and a direct-accept bit D. Let E denote the existing type 0 selected write with old R0=C0=1, new total >1, outside adjustment, R5=R8=0. Let F denote the captured frame arm and L denote live C9=R9. On any edge, the existing hold is `CLKEN && E && F`. It delays horizontal progress only on first direct acceptance. Pre-edge `D || W` feeds `r0_widen_step`, with the same immediate snapshot/type mask. The wrapper consumes it on CLKEN through its existing frame-arm or non-wrapping 1→2 qualification. See `rtl/CRTC.v:217–229,367–371,392–443`.

| Clock input | Old D after edge | Old W after edge | One obligation Q after edge |
|---|---:|---:|---:|
| Reset, SNA load or type 1 | 0 | 0 | 0 |
| CLKEN with direct E and F | 1 | 0 | 1 |
| Other CLKEN | 0 | 0 | 0 |
| Between CLKEN edges | D | W or (E and (F or L)) | Q or (E and (F or L)) |

The lifecycle clear establishes Q = D or W. Every row preserves that relation. The current consumer uses the **old** Q even when that edge admits new work. Different admission times therefore require one shared pending bit; collapsing horizontal hold, kept equality and adjustment eligibility into that bit would discard observable distinctions. This proves one bit sufficient in the existing interface. Recovering the obligation from unrelated state would require a different proof. The implementation explicitly writes 1 or 0 on direct replacement. This retains Verilog's procedural handling of an unknown predicate after reset.

The one-shot proof extracts the participating posedge assignments and the step output from the two actual engine sources. It compares the unmodified qualification and hold expressions, abstracts E/F/L as arbitrary and checks induction and output equality with Z3. All seven negated Boolean claims are unsatisfiable. An additional enumeration checks 65,536 transitions with four-state control inputs and all four reset-established Boolean D/W states. Arbitrary unknown pre-reset latch contents are outside the proof. The module's output relation plus unchanged consumers give an inductive argument for downstream pins. The proof concerns the quotient of these two bits, not an independently verified whole-chip specification.

**Observability matters here.** The soak hashes the old D spelling just after CLKEN. W is then zero, so Q has exactly D's old value at that sample. Two tracked diagnostic tops also export that spelling as `pending`. Its type 0 value between CLKEN edges now describes either pending route. Of those two tops, only the T80 bench reads that port (`sim/crtc_t80_test.cpp:307`, type 1). The B9 host does not read it. The three other C++ checks named `pending` in `sim/crtc_cpu_phase_test.cpp` bind to the type-1-only `rfd_r0_pending` in `sim/crtc_cpu_phase_top.sv:48`. The private W signal has no tracked consumer outside the old engine. Frozen private trace adapters which exported W and D separately still belong with their frozen models. To observe the new engine, record current write/CLKEN and Q if route provenance is needed. Do not alias Q to both old probes and present the result as an old-format trace.

## An original-CPC discriminator with a measurable pin

Use a type 0 CPC with normal CPU/GA waits. Both runs start with the §7.2 drift calibration and prepare the same non-last row, R4=8, R9=8, R5=R8=0. A first OUT writes R0=1. The current C0/C9 sequence from the first target ED, one character per column, is **58/4, 59/4, 0/5, 1/5, 0/6, 1/6, 0/7, 1/7, 0/8, 1/8**. C4 remains 6. Relative to the first ED, both trials present 63 to the *same* port BD00 during the last 1/8 cell. The different CPU instruction supplies the timing distinction without changing CRTC inputs or fitting a phase sweep.

The early tail is `ED 51 00 00 00 ED 59`. The late tail is `ED 51 04 00 ED A3`. D=1, E=63, BC=BD00 initially. Both guests execute `LD HL,BEE4` during an equal-length setup interval. That address contains the literal 3F operand. `INC B` sets B=BE before OUTI decrements it to BD. The late run observes a real memory read of 3F at BEE4, then a qualified BD00 I/O write. Earlier 3F→7F controls used different low address bytes. This pair removes even that difference. Onsets differ by 48 master ticks, and the write ends coincide.

**Physical readout.** Capture raw CRTC HSYNC, the CRTC-selected register-data writes, data and character clock. Align to the **first common selected write** (BD00, data 01) or the common trailing edge of the second (data 3F). Check the second write's phase/order in both runs. Compare the time to the next raw HS rise. R2=46 and R3l=14 are stable, the previous pulse has ended and French §15.2.1 p149 gives the ordinary pulse for these exact values. Starting from C0=0 instead of 2 takes two extra characters to reach 46. Relative to the early control the incumbent predicts **0 µs** and universal terminal retention predicts **+2 µs** for late OUTI. Both predict 64 µs to the following rise. Nominal clock scaling, the exact absolute RTL tick and propagation through the GA/monitor need not be assumed for the differential verdict. A missing control pulse, mismatched bus phase or a third delay leaves both rules open. This horizontal measurement alone cannot identify vertical state or a physical latch. If vertical outcomes are needed, capture RA during that same interval: in the stated noninterlaced geometry C9=8 versus 0 differs on RA3.

### Reading the result on a CPC screen

The operator disk, `R0.DSK`, runs the same timed pair and prints two PPI port B bit-0 samples. Set R7=8 while C4=6, in a 17-µs replacement for 17 NOPs before the existing register setup. The first common write, selected port, C4/C9 prehistory and HS measurement stay the same. Sample VS once before the first widened-line end and once after it. In the live model the row-only advance leaves C4=7/C9=8, so that next ordinary widened end enters C4=8/C9=0 and starts VS. If the late write wraps normally, C4=7/C9=0 immediately after the critical edge. Row 8 is still nine 64-µs lines away. Both samples then precede VS. Neither prediction needs a special R7 comparison on the row-only landing at 7.
