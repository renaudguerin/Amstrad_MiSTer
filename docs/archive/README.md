# Archived top-level ledgers

These files preserve, verbatim, the dated history that used to live in the top-level status and
review documents. They record provenance: which commit, review run, RBF or hardware report
established a result, and in what order. They are not the current position. Read
[current-status.md](../current-status.md) for the handoff, [backlog.md](../backlog.md) and
[implementation-roadmap.md](../implementation-roadmap.md) for open work, and
[review-debt.md](../review-debt.md) for review obligations still open.

Relative links inside these files were adjusted for this folder. Backticked paths are relative
to `docs/`, as they were in the original files.
